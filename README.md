# Source Code and Data
Source code and data to generate analyzes of the article "An empirical Likelihood Ratio framework for interpreting morphological correspondences in forensic facial comparison".

# Manuscript
Morphological comparison of facial features is a recommended approach for assessing correspondence between images in forensic facial identification. However, identifying morphological correspondences alone does not indicate how strongly that evidence supports one identification proposition over another. The Likelihood Ratio (LR) framework offers a means of addressing this issue by comparing the probability of the observed evidence under the proposition that the images originate from the same person with its probability under the proposition that they originate from different people.

Although the use of Likelihood Ratios in forensic facial identification has largely developed in connection with automated facial recognition systems, its application to morphological comparison has received comparatively less attention. This study uses an empirical approach to investigate, across simulated scenarios, how the evidential strength of morphological correspondences changes as the number of observed correspondences increases, and how this pattern is affected by both the amount and the type of facial information available.
